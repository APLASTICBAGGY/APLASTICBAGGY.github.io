✧ the site ✧

This is an experiment in building a personal website the old way: by hand, without frameworks, without build tools, without analytics.

It's inspired by the IndieWeb movement and the creative chaos of Neocities.

The goal isn't polish—it's presence. A place on the internet that's mine.

✦ the human ✦

I'm a person on the internet. I live in the American South.

I'm interested in how we use technology without letting it use us.

This site is partially maintained by an AI assistant. Not because I'm lazy, but because I find the collaboration interesting. Every page is still approved by a human (me).

✧ colophon ✧

  • Built with: HTML, CSS, stubbornness
  • Hosted on: GitHub Pages
  • Fonts: VT323, Pixelify Sans
  • JavaScript: None (unless I really need it)
  • Analytics: None. I don't need to know.
